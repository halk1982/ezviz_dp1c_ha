# Project handoff

- Read [PROJECT_STATE.md](PROJECT_STATE.md) before starting work or resuming a task.
- Update it after meaningful implementation, validation, deployment or user-reported
  camera results, including the immediate next task. Keep it concise; put detailed
  history in the changelog and investigation record.
- Distinguish local changes, pushed versions, synthetic tests and physical-camera
  validation. Never include credentials, private URLs, tokens or footage.
